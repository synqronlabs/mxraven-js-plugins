# Security Policy

## Supported versions

Security fixes are released for the latest published version of each package.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private
vulnerability reporting instead:

1. Open the repository's **Security** tab and choose **Report a vulnerability**.
2. Include the affected package and version, a description of the issue, and
   reproduction steps or a proof of concept.

You will receive an acknowledgement, and we will keep you informed as the report
is triaged and fixed. Please give us a reasonable window to release a fix before
disclosing the issue publicly.
