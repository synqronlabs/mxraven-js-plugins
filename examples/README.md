# Examples

Reference snippets that show how each adapter plugs into
`Message.render(renderer, input)` from `@mxraven/mail`.

- [`react.tsx`](./react.tsx) — render a React element with `@mxraven/react`.
- [`vue.ts`](./vue.ts) — render a Vue node with `@mxraven/vue`.
- [`handlebars.ts`](./handlebars.ts) — render a Handlebars template with
  `@mxraven/handlebars`.

They are illustrative, not runnable: the credentials are placeholders, and each
file starts with `@ts-nocheck` so the workspace typecheck ignores it.

For detailed, runnable examples of the SDK and the plugins, see
[`synqronlabs/mxraven-examples`](https://github.com/synqronlabs/mxraven-examples).
